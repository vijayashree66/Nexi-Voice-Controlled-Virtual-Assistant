# Nexi - Voice Controlled Virtual Assistant 🎙️

Nexi is a browser-based virtual assistant that listens to your voice, understands commands and replies with speech. It is built with JavaScript and the Web Speech API.

## Features
- Speech recognition and spoken replies
- Time-based greeting (morning, afternoon, evening)
- 10 predefined voice commands
- Google Search as a fallback for any other question
- Animated particle background and voice animation
- One-click mic button

## Voice Commands
- "Hello"
- "Who are you"
- "What is your name"
- "Open YouTube"
- "Open Google"
- "Open WhatsApp"
- "Play song"
- "Which is your most liked song"
- "What time is it"
- "Do you like your boss"

Anything else is searched on Google.

## Tech Used
- HTML5
- CSS3
- JavaScript
- Web Speech API
- particles.js

## How to Run
1. Download or clone this repo
2. Open `index.html` in Google Chrome
3. Click the button and allow microphone access
4. Speak a command

## Note
Works best in Chrome or Edge. Allow pop-ups for YouTube and Google to open.
